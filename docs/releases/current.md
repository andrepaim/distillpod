DistillPod 0.16.0-alpha.1 adds a voice preview: pause your podcast, ask about what you just heard, hear a short answer, then return to listening.

- **Voice on the phone:** save your OpenAI project API key in **Settings → Voice**, then use **Ask about this** in the player. A listening timer and live microphone waveform show when your question is being recorded. Answers appear in a bounded sheet; **View last answer** reopens the latest response without another request. An optional setting replays the preceding three seconds after an answer.
- **Headphone controls in one place:** **Settings → Playback & headphones** configures **Previous track → Save moment** and **Next track → Ask about the podcast**, with setup, permissions and readiness feedback. Gesture and single-earbud instructions expand under **Headphone setup**. Both shortcuts default off; existing choices are retained. **Moment saved sound** also applies to captures from the phone and car.
- **Locked-phone voice:** enable Next track voice, grant microphone/notification access, and start playback with DistillPod open. Wait for **Headphone voice ready** before locking the phone. Wait for the tone to speak; another Next press finishes the question or stops the answer. Bluetooth voice requires Android 12+; wired/USB headsets with microphones are also supported. Headset disconnection or a call can leave playback paused. The app does not substitute the handset microphone for an unavailable headset.
- **Android Auto preview:** supported Car API 8 hosts can expose native **Ask** and **Library** actions through the usual DistillPod launcher entry. Open that entry first; a separate Voice icon is not required. Standard media controls also advertise Ask when the car voice session is available. Reconnect Android Auto after updating. Browse tabs now have icons so their highlights and labels align correctly. Unsupported hosts do not fall back to the phone microphone.
- **Voice reliability and compatibility:** buffered answer playback avoids a false “Voice unavailable” error after a completed answer. Native libraries now use 16 KB alignment to address the earlier compatibility warning. Setup guides, troubleshooting and privacy documentation have also been refreshed.

Voice requires a publisher or local transcript covering the current listening position, network access, microphone permission and a separate OpenAI API key. Spoken questions and selected transcript excerpts go directly to OpenAI and use that key's API allowance; connecting ChatGPT alone does not enable voice. The API key stays encrypted on the phone, outside backups and sync. Existing preview keys are retained. The last answer stays in memory, with no saved conversation history. Normal completion resumes only when the original playback session remains valid; manual playback changes or interruptions can keep it paused.

This is a personal-alpha preview, not a claim of Play Store eligibility or compatibility with every car/headset. Earlier phone trials and Desktop Head Unit checks establish their recorded scenarios; they do not validate this signed APK on physical head units. Real-car microphone routing, Bluetooth gesture delivery, single-earbud/multipoint behavior, calls, navigation and sustained battery use still need broader acceptance. The S25 alignment check used a 4 KB kernel; execution on a true 16 KB kernel remains unverified. No owner-phone installation or live paid voice request is part of this publication.

Install the signed APK as an update; do not uninstall. Version code **33** is above the published 0.15.0 build (24) and recorded private S25 previews through code 32. The application ID, signing certificate and Firebase client configuration are retained. There is no database, backup-format or sync-protocol migration. Headphone preferences remain device-local; credentials and transcripts stay outside cloud sync. Update all clients before explicitly enabling contextual-moment sync; paid content sync stays disabled. Android 10+; ARM64 and x86_64.
