DistillPod 0.24.0-alpha.1 shows when subscribed YouTube videos were published and what their creators wrote about them. It also fixes a diagnostics bug that could discard every pending report at once.

- **YouTube publication dates and descriptions.** Videos from subscribed YouTube channels and playlists now show their publication date in episode lists and on the episode page. The episode page also shows the video's original description. Each refresh reads YouTube's public feed for the channel or playlist, which covers the newest 15 videos. Older videos and videos already in your library get their details the first time you open their episode page. While the details load, the page says it is checking. If YouTube can't be reached, the page says so and offers **Retry**. If YouTube has no date or description for a video, the page says that it is unavailable. DistillPod never invents a date or description. Dates outside the current year include the year. Videos that YouTube dates only by day keep that calendar day in time zones behind UTC.
- **Ordering with real dates.** Episode order within a show is unchanged. Views ordered by date across shows now place dated YouTube videos at their real publication dates instead of after every dated episode. These views include the library list and the Shows "latest episode" sort and card date. Show automation now applies its usual start date to newly found dated YouTube videos, the same as podcast episodes.
- **Diagnostics outbox fix.** If pending diagnostic reports exceeded the 5 MB limit, DistillPod deleted all of them instead of only the oldest. It now removes only as many reports as needed to get back under the limit, starting with the oldest routine reports.

Install the signed APK as an update over your existing DistillPod installation. Version code **45** retains the application ID and signing identity. Database schema 12, portable backup schema 7, Firebase protocol, rules and distribution configuration are unchanged. Publication dates and descriptions are stored only on this device and are not synced. The voice preview remains enabled, and automatic cleanup remains disabled. No backend deployment is required.

**Privacy:** refreshing a YouTube channel or playlist now makes one extra request, without your account, to YouTube's public feed. Opening a YouTube video that is missing details makes one more lookup for that video. See [privacy](https://github.com/andrepaim/distillpod/blob/v0.24.0-alpha.1/docs/privacy.md).

Automated tests cover the YouTube feed parsing, the merging of details, filling in details for older videos, the date and description messages, and the diagnostics outbox limits. Full hosted Android, native, Firebase and isolated-emulator validation passed on the merged source of both changes. The YouTube feed was compared manually against yt-dlp for one public channel and one public playlist on 2026-11-12. YouTube can change that feed without notice. No new physical-device run, signed upgrade on the owner's installation or live cross-device test was performed for this release.

Bulk audio cleanup, automatic retention, local transcript deletion and the ChatGPT integration remain unfinished and are not included.
