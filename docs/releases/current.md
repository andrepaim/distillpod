DistillPod 0.39.0-alpha.1 fixes the error page after ChatGPT sign-in, keeps the status of queued transcripts current, adds a way to report an AI result, and targets Android 16.

- **ChatGPT sign-in no longer ends on "connection refused".** After you approved the sign-in, the browser could show an error page although the app had received the approval ([#331](https://github.com/andrepaim/distillpod/issues/331)). The browser now shows "Connection received. Return to DistillPod now to finish signing in." Return to the app to complete the connection. If you return after the approval has expired, the app says "Sign-in expired. Start a fresh attempt." and no longer blames the connection.
- **A queued transcript says what it is really waiting for.** After "Only transcribe while charging" was turned off, a queued transcript could keep saying "waiting for a charger" ([#336](https://github.com/andrepaim/distillpod/issues/336)). Its status is now updated when a transcription setting changes, when another transcript starts or finishes, and when you open the app. A transcript waiting behind another shows that one's progress, for example "Queued · after another transcript (62%)", and Transcript tools name the episode being prepared first. Transcripts are still prepared one at a time, in the same order as before.
- **Report an AI result.** Saved takeaways, summaries and chapters, episode answers, explanations, share posts, podcast suggestions and spoken answers each have a **Report this result** action ([#324](https://github.com/andrepaim/distillpod/issues/324)). It shows the exact message first, lets you leave the result text out, and then opens your own email app. DistillPod sends nothing itself.
- **Privacy policy in the app.** **Settings → About DistillPod → Privacy policy** opens the [hosted policy](https://andrepaim.github.io/distillpod/privacy.html). The same link sits next to the ChatGPT, sync and diagnostics consent texts ([#325](https://github.com/andrepaim/distillpod/issues/325)).
- **Targets Android 16.** The app is built for Android 16 (API 36), which Google Play requires ([#321](https://github.com/andrepaim/distillpod/issues/321)). On tablets and foldables running Android 16, full-screen video no longer forces landscape; it stays in the current orientation. Nothing else changes for users, and Android 10 to 15 behave as before.
- **Preparation for Google Play.** The project can now build a separate Google Play version without YouTube sources, the GitHub update check and library sync ([#326](https://github.com/andrepaim/distillpod/issues/326)). **This APK is the GitHub version and keeps all three.** No Google Play version is available yet.

Install the signed APK over the existing app; do not uninstall first. This personal alpha keeps application ID `dev.distillpod.android` and the existing signing identity, and raises the version code to **64**. Database schema, backup file format, diagnostics journal format and Firebase rules/protocol are unchanged from 0.38.1-alpha.1. Downgrading the APK is not supported.

**Known limits:**

- **Sign-in page after a minute.** The app answers the browser for up to 60 seconds after the approval. A reload of that page later, or after you have returned to the app, is refused as before. Why the browser asks more than once was not established.
- **A queued transcript that Android has not started.** The app cannot see a deferred background request that Android is holding back; such a transcript says "waiting to start".
- **Deleting a sync account is still by email.** In-app deletion needs a change to the cloud rules that has not been made ([#323](https://github.com/andrepaim/distillpod/issues/323)); see the [data deletion page](https://andrepaim.github.io/distillpod/delete-account.html).
- **Not checked on a phone:** the Report this result screens, the new queued-transcript texts, the "Sign-in expired" message, and tablets or foldables.
- **Still open from earlier releases:** the limits listed in the [0.38.1-alpha.1](https://github.com/andrepaim/distillpod/releases/tag/v0.38.1-alpha.1) notes and earlier, including long background downloads that wait until DistillPod is opened ([#292](https://github.com/andrepaim/distillpod/issues/292)).

**Validation:**

- **Hosted CI:** every change passed full CI on its pull request, on a head that contained the changes merged before it: builds, unit and Robolectric tests, lint, Firebase rules, native checks and emulator acceptance, which now runs on an Android 16 image. Since [#329](https://github.com/andrepaim/distillpod/pull/329) CI also builds and tests the Google Play variant and inspects both APKs. Several runs first failed on HTTP 429 from Maven Central while downloading test libraries and passed when rerun ([#335](https://github.com/andrepaim/distillpod/issues/335)); one emulator failure in [#334](https://github.com/andrepaim/distillpod/pull/334) was a real defect and was fixed before merging.
- **Phone (Galaxy S22, Android 16):** checked with separately installed test builds of the same code, not with this APK.
  - Android 16 target ([#330](https://github.com/andrepaim/distillpod/pull/330)): updated in place with the library kept; ChatGPT sign-in connected; with the screen locked, playback advanced in real time, a transcript ran as a media-processing foreground service and completed, and a 70 MB download finished after the app left the foreground.
  - Sign-in page ([#332](https://github.com/andrepaim/distillpod/pull/332)): after approval the browser showed "Connection received…" and the app connected on return.
- **Publication:** the release workflow separately reruns full validation, release lint/assembly and signing. The downloaded assets are then checked for checksums, source identity, package/version, non-debuggable state, retained certificate and alignment.
