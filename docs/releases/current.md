DistillPod 0.19.1-alpha.1 makes changes to the Wi-Fi / unmetered downloads setting apply to work that is already queued.

- **Update queued work:** changing the setting updates waiting audio downloads, transcription-model downloads, and transcript preparation that needs internet. Existing partial downloads, request identity, retry history, delays, and transcript checkpoints are preserved. Cancelled or completed work is not restarted.
- **Recover saved settings:** startup reconciles queued work with the saved policy, including older online transcript lookups whose episode audio is already downloaded. Local-only transcription keeps its power requirements without gaining a network restriction.
- **Keep active transfers safe:** an attempt already in progress continues under its original constraints. A later retry uses the new setting. Use Pause if you need to stop a current transfer immediately. Settings now explains this behavior.

Install as an update without uninstalling. Version code **37** supersedes code 36. The application ID, retained signing identity, database schema, portable backup format, and Firebase protocol are unchanged. The policy remains local to this device. Manual refresh, AI requests, account operations, and cloud-sync policy retain their existing behavior. Voice preview stays enabled and paid content sync stays disabled.

This patch contains [PR #26](https://github.com/andrepaim/distillpod/pull/26) on top of [0.19.0-alpha.1](https://github.com/andrepaim/distillpod/releases/tag/v0.19.0-alpha.1). The YouTube/videocast and show-automation features, their GPL-3.0-only source distribution, and their existing alpha limitations remain unchanged.
