DistillPod 0.14.0-alpha.1 prepares transcripts when you play an episode and confirms newly saved distills with a short pen scribble.

- **Automatic transcripts:** preparation starts from app playback, system controls and queue advancement. Settings → Local transcription → Transcribe when playing is on by default, including after an upgrade. Existing text and jobs are reused; explicit pauses, failed/partial work and model/language changes do not trigger unwanted regeneration.
- Preparation uses suitable publisher transcripts, optional existing online lookup, then local Whisper under the existing network, battery, charging and storage policies. Model downloads remain explicit. Online lookup stays opt-in; audio is not uploaded for transcription.
- The player shows preparation progress and Pause transcript. Turning automatic preparation off stops new requests; stopping playback or disabling the setting does not cancel accepted jobs. Use Pause transcript to stop one. Local processing can increase battery use and audio downloads.
- **Saved confirmation:** a 550 ms pen scribble plays after a new moment is committed, including app, lock-screen and Android Auto captures. It uses media volume and the current output. Duplicate taps, recovery and failed saves stay silent. Mute it in Settings → Import & notifications → Distill confirmation sound. Both new settings stay on this device.
- Contextual distills, source-aware replay, version history, Android Auto and social sharing from previous releases remain available. This update adds no database, backup-format or sync-protocol migration. Accounts still use the existing explicit protocol-3 upgrade for contextual moment sync; update all installations before enabling it. Paid content sync remains disabled and transcripts stay local.

Automated coverage includes playback scheduling and queue transitions, settings persistence and independence, transcript revision preservation during downloads, durable capture and sound suppression. The combined feature source `8fabf40` passed Android CI, including Kotlin tests, lint/build, native checks, Firebase rules and isolated Android acceptance. Publication additionally requires these checks on the exact release commit and release lint/assembly. The isolated suite exercises streaming with local Whisper and native confirmation playback. This release has no new physical-phone installation or car-routing validation; sustained playback/transcription battery behavior and broader Bluetooth/device coverage remain open. Contextual-distill live-model comparison and blind human assessment also remain outstanding.

Install the signed APK as an update over the compatible alpha app; do not uninstall. The application ID, signing certificate and required Firebase client configuration are retained. Android 10+; ARM64 and x86_64. Version code: 23.
