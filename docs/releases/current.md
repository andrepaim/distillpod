DistillPod 0.21.0-alpha.1 brings clearer Settings and storage controls, safer queued transcription, easier show navigation, and more useful opt-in troubleshooting.

- **Go from an episode to its show:** use View show in the expanded player or episode details. Back returns to where you were without changing playback, queue, position or speed. Unavailable shows are labeled rather than offering a broken link.
- **Find the right setting:** Settings now groups Your library, Playback & transcripts, and App access & privacy. Notification access has its own page, charging preferences live under Transcript preparation, and Moment saved sound has one editor. Existing saved values and defaults stay unchanged.
- **Recover notification access:** the page refreshes after returning from Android Settings and after permission requests. If notifications are denied, the Settings recovery action remains available.
- **Understand and manage storage:** see actual logical file sizes for completed audio, partial/cache files and models. Manage downloads offers confirmed removal of selected completed audio or a paused partial, with checks for active playback, queue and transcription use. Saved text and listening progress are retained. Lowering the audio quota does not delete existing downloads.
- **Know what protects your library:** clearer guidance distinguishes Library sync from manual file backups, explains included and excluded data, and shows backup age. A successful file read-back does not prove that a storage provider uploaded it to the cloud. This update does not enable additional sync or automatic backups.
- **Keep queued transcription under the chosen network policy:** changes to Wi-Fi / unmetered downloads only now cover requests after capture priorities or transcript checkpoints move. Modern requests retain their identity and scheduling metadata. On the first reconciliation of older requests, an active transcript chunk can finish before pending legacy jobs are replaced; their old IDs, delays and retry history are not retained, but saved transcript text and checkpoints are. This first reconciliation can temporarily delay the Settings action and new audio/model enqueue operations.
- **Respect Pause:** an older missing-model check no longer overwrites a paused transcript or a newer transcript revision.
- **Improve optional diagnostics:** bounded critical-event capacity, correlation across dependencies and retries, separate generation/review outcomes, and content-free context-readiness evidence make distillation problems easier to investigate. Diagnostic summaries contain no transcripts, prompts, quotes, raw provider responses or credentials. Collection still follows existing consent. Private investigation tooling reads authorized diagnostic records; it does not add a new upload destination, AI request or background schedule.

Install the signed APK as an update **without uninstalling**. Version code **39** supersedes published code 38 and retains the application ID and signing identity. Database schema 11 and portable backup schema 7 are unchanged. Older backups remain importable; new exports still require an app supporting schema 7. Installation-local diagnostic provenance is excluded from backup export/import. Firebase protocol/rules and sync scope are unchanged, paid content sync stays disabled, and voice preview remains enabled with its existing setup and opt-in requirements. The matching GPL source archive, component manifest and notices accompany the APK.

**Known alpha limitations:** diagnostics are bounded and best effort, not a complete history or proof of provider billing; missing evidence remains unknown. Diagnostic changes do not improve or guarantee generated content quality. Storage usage is a refreshable logical-byte snapshot, and file deletion plus database updates are not atomic across process death. Existing YouTube limits remain: public extraction can be slow or unavailable by video/device/network, private/restricted/live content is unsupported, imports are bounded to 200 entries, and offline downloads contain audio only. Carrier billing, long-duration background scheduling and unplugged battery drain were not measured.
