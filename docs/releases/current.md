DistillPod 0.20.0-alpha.1 makes video shows easier to find and watch, with immersive landscape fullscreen and stable search results.

- **Fullscreen video:** use the fullscreen button, or turn the phone sideways while watching with auto-rotate enabled. Tap the picture to reveal play/pause, seeking, Distill, voice question and exit controls. Controls remain visible while paused or interacting. Back returns to the inline player; its controls stay reachable in landscape. Playback position, speed and queue stay with the same player. Leaving the app restores audio.
- **Distill and ask while watching:** fullscreen Distill saves the current moment without leaving the player. Voice question uses the existing voice setup and session sheet. Voice preview remains enabled and still requires its normal key, microphone permission and opt-in.
- **Find the actual channel:** All, Audio and Video filters distinguish podcast results from YouTube channels and playlists. Results from slower providers append without displacing already displayed results. Loading, failure and retry remain specific to each provider.
- **Latest channel videos first:** following a channel uses its latest Videos tab. Refresh persists source order rather than alphabetizing undated videos, while preserving progress and downloads. Choose the channel result for newest uploads. Dated playlists sort newest first; undated playlists retain the publisher's order, which can be nonchronological. Refresh existing subscriptions to apply the corrected ordering.
- **Less repeated loading:** valid signed streams can be reused beyond the previous two-minute cutoff, with a safety margin before expiry and a 30-minute maximum. Rejected URLs still get one fresh resolution. Cold starts remain dependent on YouTube and the network. Video is streamed; offline YouTube downloads still contain audio only.
- **Download settings:** changes to Wi-Fi / unmetered downloads only now reconcile queued audio/model downloads and the current identified transcript request, including online transcript lookup for locally downloaded audio. Partial files, request identity and saved transcript progress are retained. An already-running attempt intentionally finishes under its original constraints; use Pause when it must stop immediately.

Install this signed APK as an update **without uninstalling**. Version code **38** preserves the application ID and retained signing identity. Local database schema 11 adds video ordering metadata and preserves existing records. This version imports older backups; newly exported backups use transfer schema 7 and require an updated app for restore. Firebase protocol/rules are unchanged, paid content sync remains disabled, and YouTube sources stay local for compatibility with older clients. The matching GPL source archive, component manifest and notices accompany the APK.

**Known alpha limitations:** public YouTube extraction can be slow or unavailable by video/device/network; private, restricted and live content is unsupported. Imports remain bounded to the first 200 source entries. A pre-existing queued-transcription edge case remains: if a capture changes the next segment while an older request is queued, that older request can retain its previous network setting. Pause that transcription before changing the setting, then resume under the new policy. The separate corrective patch is not included in this release. Carrier billing, long-duration background scheduling, unplugged battery drain and live paid voice requests were not measured.

Validation evidence is recorded in [PR #26](https://github.com/andrepaim/distillpod/pull/26), [PR #32](https://github.com/andrepaim/distillpod/pull/32) and the [video experience record](https://github.com/andrepaim/distillpod/blob/v0.20.0-alpha.1/docs/android/video-experience.md). The unchanged video code passed automated and emulator checks plus non-destructive S22 channel/playback/fullscreen/seek/capture/Back/background acceptance, with the owner session restored. Network-policy device checks used isolated validation packages. Publication is gated by exact-candidate main CI and the release workflow's build, signature and alignment checks; earlier phone evidence does not claim that this new version was installed on the phone.
