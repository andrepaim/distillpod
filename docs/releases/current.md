DistillPod 0.19.0-alpha.1 adds public YouTube playlists and videocasts, automatic preparation of new show episodes, and per-episode ad controls.

- **Discover and follow:** YouTube playlist results arrive independently from Apple podcast results. Add a public playlist or video link directly; retry an unavailable provider without discarding other results.
- **Audio or video:** episodes start in audio mode. Choose Video in the player, then return to audio at the same position. Leaving the app restores audio and cancels pending video loading without waiting for the screen to reopen. Background playback, queue and speed stay with the existing media service. Source swaps preserve the starting position even while an earlier timeline is preparing.
- **Offline learning:** download YouTube audio for offline playback and local transcription. Video remains streamed; offline downloads contain audio only.
- **Prepare new episodes automatically:** opt in on a followed show. The first successful refresh establishes a baseline; later discoveries can download, transcribe and generate summaries, chapters and ad markers. Analysis sends transcript text to ChatGPT and uses your plan allowance. Feed checking defaults to six hours, with custom intervals from 1–168 hours; Android may delay work.
- **Skip marked ads:** after a current downloaded episode has been processed, choose skipping for that episode and review suggested ranges. Review exclusions persist across off/on toggles; new analysis requires a new opt-in. For YouTube, skipping applies to downloaded Audio mode, rather than streamed Video.
- **Reliability:** bounded extraction deadlines/retries, scoped cancellation, short-lived stream caching and one refresh of a rejected initial CDN URL. New optional diagnostics cover extraction and video/audio transitions without collecting titles, URLs, audio or transcripts.
- **Source and license:** the Android app, shared core and their original build/release scripts are GPL-3.0-only. Settings → About DistillPod provides license/source access. This release includes the matching source archive, pinned upstream source archives, component manifest and third-party notices; independent legacy/web code retains its existing terms.

Install as an update without uninstalling. Version code **36** supersedes code 35. Application ID and retained signing identity stay compatible. Database schema 10 adds local automation/ad-preference tables while preserving existing records. The portable backup format and existing Firebase protocol remain unchanged. Automation intent, jobs and per-episode ad preferences stay local and are excluded from portable backups and cloud sync. YouTube subscriptions, progress and saved moments remain local under that protocol; RSS sync keeps its existing behavior. Voice preview stays enabled and paid content sync stays disabled.

This personal-alpha import loads at most the first 200 playlist entries. Unknown dates remain unknown. Private/restricted/live content is unsupported, and YouTube availability can change by device/network. Audio fallback requests cannot prove audible output. Bluetooth/head-unit behavior requires separate hardware evidence. The six-hour unattended automation interval, deep Doze and unplugged battery drain have not been measured.

Validation coverage and limitations are recorded in the [delivery receipt](https://github.com/andrepaim/distillpod/blob/v0.19.0-alpha.1/docs/android/evidence/videocast-delivery.md) and [PR #16](https://github.com/andrepaim/distillpod/pull/16), including the final physical-device and publication gates. Native Whisper crash collection remains a separate follow-up.
